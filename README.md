# ✅ To-Do List Flutter App

A simple and clean **To-Do List** application built using **Flutter**.  
This app focuses on UI/UX only — no database or persistent storage is used.

## ✨ Features

- 🧾 Add tasks temporarily during runtime
- 🧹 Remove tasks
- 🎨 Minimalistic and clean UI
- ⚡ Smooth performance and responsive layout

## 🚀 Getting Started

> Make sure you have Flutter installed on your system.  
> [Flutter Installation Guide](https://docs.flutter.dev/get-started/install)

```bash
git clone https://github.com/adamwassal/todo_list_flutter.git
cd todo_list_flutter
flutter pub get
flutter run
```

## 📌 Notes
❗ Data is not saved after app is closed (no backend or local storage).

This project is meant to showcase UI/UX design only.
